# 五小时额度

规则和场景示例见 [服务中心部署说明](../deploy/SERVICE_CENTER.md)。

额度为有效订阅七天美元额度之和的 15%，消费从数据库 usage_logs.actual_cost 读取，按用户计算严格滚动五小时。非尖峰仅统计用量，不额外限制请求；尖峰达到额度才限制后续新请求，退出尖峰立即放行。

压力默认达到 100% 进入尖峰，低于 90% 退出。账号真实窗口用于判断压力，不参与个人额度换算。压力过期或数据库读取失败时放行额外限制，原有订阅和 API Key 额度仍独立执行。

个人用量、重置审计和订阅均保存在数据库，重启不丢失。旧版本的采样校准、Redis 计量、请求预留和重放任务已移除；历史迁移保留兼容，不再读取旧计量表。独立五小时倍率已移除，请在订阅分组设置美元额度。

接入账号优先供所属用户使用，忙碌时自动回退公共池。暂停或删除账号会暂停失去资格的自动订阅；恢复账号只在原有效期内恢复，保留已消费用量。管理员手动授予或购买的订阅不受此联动影响。
